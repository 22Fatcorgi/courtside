# COURTSIDE — 第四版自動更新修正

NBA 官方統計、球員名單與賽程來源在 GitHub Actions 回傳 HTTP 403。第四版改由 ESPN 逐場資料更新最新賽季統計、近五場排行與目前球隊；NBA 官方新聞與已核對 NBA ID 的球員照片保留。

## 上傳這個修正包

1. 將壓縮檔解壓縮。
2. 開啟 https://github.com/22Fatcorgi/courtside/upload/main 。
3. 將解壓後的 index.html、scripts 資料夾、data 資料夾與 README.md 一起拖入上傳區。直接放在儲存庫最外層，不要再包一層資料夾。
4. 按 Commit changes。保留原有 .github/workflows/update-data.yml；這次不需要重新上傳或修改它。
5. Actions → Update NBA data → 最新執行。摘要應顯示 Updater: v4 與 ESPN 來源。完成且沒有來源錯誤時，工作流程才會顯示成功。
6. 開啟網站，按 Ctrl+F5 重新載入。預設來源為 ESPN，焦點卡片、球員資料與來源說明均標示實際資料來源。

## 更新方式

- 原有 GitHub Actions 每 4 小時檢查，網頁開啟時與每小時讀取 data/latest.json。
- 每次取得最新賽季所有已過月份的 NBA 完賽賽程，使用 ESPN box scores 計算整季平均與各球員最近五場。熱身賽、例行賽、季後賽分開。
- 出賽滿五場才列入焦點排名，同分按英文姓名排序。命中率用投進總數除以出手總數。
- ESPN MIN 依來源精度，部分逐場時間為整數分鐘；顯示值不能視為精確到秒。
- 已完賽逐場內容壓縮快取，最近兩個比賽日重新檢查。先檢查賽季、類型、日期、球隊、完賽狀態及球員得分合計；任何場次不完整，保留該期間原資料及原取得時間。
- NBA 保存資料與 ESPN 更新資料分開保存、分開標示。NBA 保存資料不會被 ESPN 數字覆寫。
- 目前球隊依 ESPN 30 隊名單更新，統計球隊依所選期間保留，TOT 只用於實際跨隊合計。
- 已建立 NBA ID 對照的球員使用 NBA 照片；沒有可靠對照的球員顯示姓名縮寫，不將 ESPN ID 當成 NBA ID。
- NBA 官方新聞由排程讀取；ESPN 與緯來 NBA 新聞維持網站開啟時與每小時檢查。來源失敗會保留舊資料及時間。
- 收藏保存在目前瀏覽器，不提供帳號與跨裝置同步。

## 驗證範圍

本機實際取得 2026–27 熱身賽 67 場、577 位出賽球員，91 位出賽滿五場；檢查完賽比分與球員得分合計。Python 解析與失敗保留測試、網站資料套用與來源切換測試通過。未進行瀏覽器視覺驗證。GitHub Actions 是否能連線到 ESPN 需在上傳後確認，來源長期可用性無法保證。
